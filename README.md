# Student Management System

## Project Description

The Student Management System is a Python-based command-line application used to manage student records efficiently.

The system allows users to add, view, search, update, delete, sort, and save student information.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Sort Students by Marks
- Save Student Data
- Load Student Data Automatically
- Duplicate Registration Number Prevention
- Input Validation and Error Handling

## Student Details

The system stores the following information:

- Registration Number
- Name
- Age
- Course
- Semester
- Marks

## Technologies Used

- Python
- File Handling
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Searching
- Sorting
- Exception Handling
